# PRD: Mehraz Sarker Portfolio Website

## Overview

* **What:** Personal portfolio website for Mehraz H. Sarker
* **Who:** Researchers, policymakers, academic institutions, community organizations, and professional contacts
* **Why:** Present Mehraz's research, policy, community-development work, publications, experience, and professional background in a curated portfolio rather than a CV-only format.

## Core Sections

1. **Home** — clear introduction, professional identity, and current focus
2. **About** — Mehraz's background, interests, and approach
3. **Selected Work** — research, policy, and community-development work
4. **Publications & Presentations** — selected publications and conference work.
5. **Experience** — curated professional timeline
6. **Education & Awards** — academic background and selected achievements
7. **Contact** — professional contact information and LinkedIn.

## Content Principles

* Portfolio, not an online copy of the CV
* Highlight selected work rather than everything
* Provide context and evidence for important work
* Make Mehraz's research, policy, and community-development identity clear
* Keep the content easy to update

## Non-Goals

* No backend
* No database
* No authentication
* No CMS
* No unnecessary interactive features
* No attempt to reproduce the entire CV as a webpage

## Technical Constraints

* Static website
* Deployable on **GitHub Pages**
* Development through vibe coding
* Must work on desktop and mobile
* No server-side functionality
* Content should be easy to edit directly in the repository

## Success Criteria

* Mehraz's professional identity is immediately clear
* Visitors can discover his selected work, publications, experience, and background easily
* Important work has supporting links/evidence where available
* Website works correctly on GitHub Pages
* Website is easy to maintain and update

## Phases

### Phase 1: Project Setup & Homepage

#### Tasks for Phase 1

* Initialize the static website project.
* Set up the basic layout and navigation.
* Build the homepage with Mehraz's name, professional identity, introduction, and current focus.
* Add responsive structure for desktop and mobile.
* Configure the project for GitHub Pages.

### Verification — Phase 1

* Website runs locally without errors.
* Homepage displays correctly on desktop and mobile.
* Navigation links work.
* GitHub Pages can successfully build and serve the website.

#### Tasks for Phase 2
