# Constraints

Some boundaries around our project.

## External

- The website will initially be deployed using GitHub Pages. Therefore, the first version must work without a server-side backend, database, or server-side code.

## Internal: Involuntary

- Shuqair have limited time to develop this site.

## Internal: Voluntary

- AI-assisted development will be used as a development tool, but it will not replace the software-development process.
- The first release will be limited to an MVP and will not attempt to implement every possible portfolio feature.
